# Findings

- 花骨朵 main 轨起点（以 1/48 拍计）：0 拍 181、2/3 拍 89、1/2 拍 38、1/4 拍 23、1/3 拍 21、1/6 拍 16、5/6 拍 9，另有 1/8、1/12 等装饰短音；时值 1/3 拍 71 个、2/3 拍 70 个。属于摇摆/三连感为主、夹杂直拍与装饰音。
- 三连网格取 Q/3 时 main 移位 302，取 Q/6 时 263（十六分网格基线 422）；Q/6 包含 1/2 拍，但每个起点须距三连格点小于 1/16 拍，十六分位置（距 1/12 拍）不会被吸进三连。
- 判断规则：拍内边界（起点权重 1、终点 0.5）三连误差须小于直网格误差的一半，所有起点距三连格点 < 1/16 拍，且至少一个边界落在非直网格位置。三份样本中直拍工程判出 0 个三连拍。
- divisions 仅在出现三连拍时变为网格 ×3（16 → 48），直拍工程的 MusicXML 与关闭三连音时逐字节相同（8/16/32 网格、合并开关均验证）。
- 拍号仅 x/4 写三连音；x/8、x/2 保持原样。
- 人声工程各轨共用三连判断，否则“合并分散独唱”会把一轨的三连位置移进另一轨的直拍；共用后合并与否音符时值一致（样本测试覆盖）。器乐工程从不合并，逐轨判断。
- 花骨朵十六分网格开三连音：main 422 → 269（单独选 main 时 263），chords 172 → 77；147 个三连拍、201 个括号；剩余移位主要是终点略早/略晚与 1/12 拍装饰短音。OSMD 正确绘制括号与“3”；简谱 main 轨 173 组。
- 简谱渲染器原本不支持一个分谱多声部，chords 轨本身有同时发声，故简谱需单选 main 才能显示（与三连音无关的既有限制）。
