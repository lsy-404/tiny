# Findings

- CASSIE 启动页（apps/cassie/src/components/TerminalEntry.vue）：全屏终端风格，逐项真实能力检查（[PEND]/[ OK ]、旋转符、点）、0.7 s 交接、右上角返回主菜单、尊重减少动态。织音机采用相同机制、自身视觉（logo 逐笔绘制、Fluent 主题色）。
- 启动画面叠在应用之上时，两处“返回 Tiny Projects 主菜单”同时可访问，project-navigation 测试严格模式报 2 个元素；inert 不被 Playwright 视为隐藏，需同时 aria-hidden。
- 拼音定位评估（完美友人.acep，96 个 ≥2 字乐句）改前：干净条件 88.5%（0 错位）；每 15% 音节后加续唱韵母 28.1%；5% 换气 60.4%；四字以上一处错字 9.4%。原因：要求连续严格相等。改后（跳过占位/续唱、音素通配、拼写归一、按编辑距离近似对齐，容差每四字一处）：各条件 97.9–99.0%，错位 1–2 句（缺字处的等价对齐歧义），无未找到。
- 花骨朵_尘only.svp：main 轨原始无重叠，但 422/520 个音符不在十六分网格上（大量三连音位置 2/3、1/3 拍），1/12 拍的极短音（“-”片段、拆辅音如 xi + .iA N）对齐到同一格，与下一音符重叠 → 第二声部（34 处）。chords 轨本身有同时发声（82 拍 sheng G4+E5 等），属真实和声。
- 花骨朵调性：音级 C D E G A 加 F 还原，无 F♯；旧算法（K-S 相关）E 小调 0.700 > C 大调 0.646。加调外音时长扣分后：花骨朵 C 大调；人立方 B 小调（原 F♯ 小调，与逐小节分析一致）；请不要带我走 B 小调、完美友人 C 小调不变。权重 2 不足以纠正花骨朵，取 3。
- 调校参数：三个 SV 工程按 50 音分阈值修正的音符均为 0，参数主要带来警告噪声；开关默认关、关闭时不发相关警告。
- 后续可做：三连音（花骨朵大量 8 分三连音位置）需要按拍自适应二/三分网格与 <time-modification>/<tuplet>。
