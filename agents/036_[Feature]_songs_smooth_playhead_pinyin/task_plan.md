# 036 [Feature] 歌曲挂接、平滑走带、拼音候选

用户（附两张截图：Track 2 汉字歌词中夹拼音 yue / ye，Track 3、4 整轨拼音）：
“歌曲应该允许deattach到工程 / 线条移动不够平滑 / 然后不同音轨和前后之间可以作为拼音补充来源，这将生成一个弹出候选框”
澄清：歌曲独立，可挂到多个工程（每个工程各记偏移），解除挂接后歌曲仍保留，拖入音频即可导入。

## 步骤
- [x] 走带平滑：getOutputTimestamp + performance.now 的听感时钟；按谱行单调三次插值（跨小节连续）；光标独立组件 + transform 亚像素移动
- [x] 歌曲：audio 存储改为独立歌曲（songs），工程设置 songId；旧版按工程 id 存的音频自动挂回；删除工程不删歌曲
- [x] 文件列表“歌曲”区：挂到当前工程、挂接数、删除（同时从各工程解除）；拖入/选择音频导入为歌曲并按同名或当前工程自动挂接
- [x] 播放栏：解除挂接、从已有歌曲挂接
- [x] 拼音候选：识别拼音歌词；来源 = 其他声部同一时间的汉字、全曲前后同读音汉字（按前后读音上下文打分）；worker 计算
- [x] 谱面弹出候选框：拼音歌词标记，点开后候选按钮（来源说明），可同时替换其他声部同一位置的同音拼音
- [x] 四语言文案、测试、README、构建
- [x] 合并进 main、推送部署、生产验证
