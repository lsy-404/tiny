# 036 调研与问题记录

- [光标不平滑] 三个原因：AudioContext.currentTime 按音频线程缓冲（约 10 ms）跳变；音符间线性插值在每个起音处速度突变；光标在 App 插槽里，每帧使 ScoreViewer 重绘且 left 百分比按像素取整。
  -> getOutputTimestamp + performance.now 估计“正在听到”的时刻（含输出延迟），不回退；按谱行（系统）拼接各小节起音点，跨小节线连续，Fritsch–Carlson 单调三次插值；PlayheadLine 独立组件 + translate3d 像素位移。
  实测（请不要带我走.svp，同机 4 s，144 Hz）：旧版 30% 帧不动、最大单帧跳 28.5 px、速度变化中位 63 / p95 337 px/s；新版 0 帧不动、最大 3 px、中位 3 / p95 16 px/s。
- [拼音候选只用本曲来源时“音 yue”给出 约/阅] 本曲从未写“音乐”的汉字 -> 加入词语来源：pinyin-pro 的 segment 能识别其词典中的词（含多音字的词，如 音乐），对相邻字（汉字或拼音）与同读音常用字组合检验；常用字表从 TextDecoder('gbk') 解码 GB 2312 一级 3755 字得到，不随应用分发字表。
- [拼音-拼音组合缓存串位] “yin|yue” 缓存同时服务 yin（右邻 yue）与 yue（左邻 yin），先算者的字被另一方复用（yue 得到“音”）-> 缓存词本身，按目标所在位置取字。
- 真实工程（在我们成为朋友之前.svp，6 声部 957 音符）：299 个拼音歌词有候选；赤羽整段拼音的“而我也迫切等待着每一”均来自诗岸同时演唱；“音 yue”→乐（词语“音乐”），“画 ye”→也（第 26 小节“许我也试”）。首次计算约 170 ms（建反查表），之后约 6 ms，放歌词 worker。
- [i18n/拼音正则] ǚ（U+01DA）不在 À-ÿ -> 用 \p{Script=Latin}；shell 编辑两次吞掉反斜杠，改用 Edit 精确替换。
