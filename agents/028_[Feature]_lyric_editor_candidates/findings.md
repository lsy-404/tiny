# Findings

- 人立方：所有声部歌词为拼音，整首歌分给 V3-1/V4-1/V5-1 及和声声部；粘贴整首歌词必须同时对所有声部，否则别的声部唱的句子都会被标成找不到。
- 局部比对（Smith-Waterman，对上 +3、多音字其他读音 +2、音素音符 +1、错字或跳过 −2）反复取最优段；第二轮允许复用已用的粘贴字，副歌只写一次也能覆盖每次演唱。
- 段落端点的零碎延伸（“没唱|我们一起唱歌”把前一句的“唱”接到副歌）净得 +1；把跳过代价提到 3 会让 V4-1 的碎句从 215 降到 205，改为修剪“只值 1 分”的端点。
- 旧规则跳过续唱韵母，把“骄傲”的 ao 也跳了；改为可选（可配对、跳过不扣分）。“层层叠叠”唱成 ceng die：重叠字第二个可选；a/ha 等哼唱可选，不计“未对上”。
- “心声/新生”正则会贪婪抓成“将心声/新生镌刻”，改为取斜杠两侧读音相同的最长一段。
- 人立方实测：582 字全部对上；V3-1 426/426、V4-1 215/215、V5-1 136/137、和声声部全对上；一次修正 803 个音符，约 50 ms。
