- [版本差异] 新版 3795 行（旧版 2427 行）：顶栏改为品牌 + 营业按钮 + 商店/图鉴 + ⚙选项菜单（夜间模式、测试修改器、存档、读档、提前结束、重新开始）；新增数据看板（天数/金币/时间卡片、今日事件卡、挑战/连击行）、推荐购买、聪明的服务员/顾客、咖啡机升级、自动存档（仅在每天打烊时写入）。测试修改器仍在（选项菜单 + F1，固定秘钥）。
- [提示词泄露] 逐条提取 <script> 内含中文的字符串（scratchpad/strings.mjs，约 290 处）与 HTML 文本、title/aria/placeholder。
  - 确认泄露：商店「经营升级」页签下的 `<p class="shop-section-note">只展示下一次升级带来的变化</p>`——是写给生成者的需求原话，玩家可见。每张卡已有“当前 Lv.x”与下一级效果，删掉不缺信息。
  - 不可见：教程第 11、12 步“（继续经营）”“（第二单流程同前）”是占位，tutorialNext 只会跳 10→13，玩家看不到；小屁孩的 effect 字段无处读取；CSS 注释（“统一布局：…”“事件与辅助状态始终使用固定的预留空间…”）不渲染。
  - 测试修改器里的“所有升级拉满（自动功能默认关闭）”随修改器一并移除。
  - 措辞偏技术但属于正常游戏文案（不改）：“每日营业模拟时长增至 N 秒”、推荐理由“服务基础已完成，可以解放手动操作”、小屁孩状态条“看菜单／点单／用餐／做菜 ×3 · 奔跑 ×2”。
- [布局] `.game-main` 生效规则为 `height:calc(100vh - 220px); min-height:650px`，但顶栏 82 + 看板 232 = 314px → 任何视口页面都比视口高 ≥94px（1920×940 页面 1034；1280×860 为 964；1366×657 时餐桌底边 682 已在首屏外）。餐桌布局 calculateDiningLayout 按餐厅可见高度居中、不足时餐厅内部滚动，故可改为 `calc(100vh - 314px)` 并降低最小高度。
- [文案与布局不符] 教程第 1 步“点击左上角「开始营业」”，新版按钮在顶栏中右侧。
- [外观] 教程框 280px 宽，多行出现单字/双字折行（“按/钮”“工/作台”“依次/制作”）；JS 定位也用 boxW = 280。
- [外观·旧配色残留] 新版主色为米色/棕色，以下仍是旧版粉/绿：教程框粉边与粉色“知道了”、通用弹窗“知道了”（.gm-btn-ok #ff6b9d）、食谱/装修购买按钮内联绿色（#2e8b57/#2d8659，经营升级为棕色 #ae766e）、“已解锁”亮绿、图鉴页签绿色描边、客人图鉴名称与商店“当前金币”“推荐购买”为旧酒红 #8b003a、每日挑战完成态亮绿。属作者美术选择，先报告不改。
- [其他] 夜间模式切换有 0.3s 过渡，截图过早会看到半切换状态，并非缺陷。日结弹窗与第 15 步教程同时出现，教程框在弹窗遮罩之后，关掉日结后仍可见，可接受。
- [小问题·未改] 服务员停靠在桌边时（TABLE_DOCK y:150）圆形会压在该桌爱心行上，爱心盖住“服”字；属于玩法坐标，改动会影响走位，先报告。
