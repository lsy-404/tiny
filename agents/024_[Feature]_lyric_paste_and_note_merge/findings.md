# Findings

- 旧粘贴逻辑：拼音/汉字转拼音/汉字替换拼音三种模式都从声部第一个有歌词的音符开始顺序替换，且要求词数与整个声部一致；只有“汉字匹配现有拼音”会查找位置，且只支持单句。用户截图正是前者（644 个目标、粘贴 4 个词）。
- 真实工程的左右续唱写法统计（间隔 ≤ 十六分）：请不要带我走.svp 中“-”多为不同音高的花腔（119 处，八分音符为主），另有重唱韵母 zou→ou、ma→a 等（15 处）；人立方 有 jiao→ao 与长音重复 a→a、xiang→xiang；完美友人.acep 有 小→小、仅→仅（真实叠字）。因此：重复同字不合并；韵母续唱视为延长；八分花腔保留。
- 初版“高”吸收八分以内任意音程，会在请不要带我走里吞掉 96 个真实花腔音；改为只吸收十六分以内。各级实测（无/低/中/高 合并数）：请不要带我走 0/0/39/39，人立方 0/0/2/2，完美友人 0/1/9/9。
