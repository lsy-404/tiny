# Findings

- Existing OSMD pages in an earlier browser sample had a valid page-sized viewBox; the `900 × 1100` fallback is only applied when no viewBox exists and ignores explicit width/height.
- The PDF pipeline rasterizes the resulting SVG viewBox to printable dimensions; scaling the OSMD SVG element alone is not a correction for sparse internal engraving. The app's fixed `Zoom=0.85` therefore does not explain the observed unused page area by itself.
- OSMD documents `GraphicalNote.sourceNote`, `GraphicalNote.getLyricsSVGs()`, and `GraphicalStaffEntry.LyricsEntries`. `GraphicalLyricEntry.LyricsEntry.Parent` returns its `VoiceEntry`; `GraphicalStaffEntry` exposes source timestamp and `graphicalVoiceEntries`. This supports exact identity mapping via parent part/voice, timestamp and pitch, without matching duplicate lyric text.
- References: https://opensheetmusicdisplay.github.io/classdoc/classes/GraphicalNote.html ; https://opensheetmusicdisplay.github.io/classdoc/classes/GraphicalLyricEntry.html ; https://opensheetmusicdisplay.github.io/classdoc/classes/GraphicalStaffEntry.html ; https://opensheetmusicdisplay.github.io/classdoc/classes/EngravingRules.html
- Evidence limitation: the already-open browser showed a different project (`vocal.svp`, 1207 notes/186 measures) than the two authorized sample files (573 notes each). Do not treat that screenshot as the target file's final visual QA.
- `renderStaffScore` now applies the requested paper dimensions and renders at `Zoom = 1`; this keeps engraving geometry in the OSMD page coordinate system instead of compensating with an arbitrary scale factor.
- Converter-generated MusicXML note IDs retain source track/note indices through tied segments. OSMD `GraphicalNote.sourceNote` maps the exact rendered lyric SVG node by part, voice, pitch, and absolute timestamp, so duplicate lyric strings remain distinct.
- The jianpu renderer reads the same MusicXML IDs and emits matching editable lyric/part labels. Staff part labels are marked only when their visible text uniquely identifies a source track; duplicate part names are intentionally left unbound.
- Browser fixtures passed: OSMD generated source-mapped lyrics and track labels with explicit SVG page geometry; jianpu rendered 102 measures / 3 parts and preserved source identity tags. Node suites passed; the Playwright wrapper is skipped when the optional package is absent.
