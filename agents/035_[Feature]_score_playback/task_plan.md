# 035 [Feature] 曲谱播放走带

用户：“也许可以加一个能播放曲谱走带的功能？这个是不是得上传歌曲”。回答：不需要上传，工程音符与速度足以在浏览器内播放；工程不含人声音频。
用户选择：“我们内置带个钢琴？但是推荐打开音频”——内置钢琴音色按谱播放，界面推荐打开合成器导出的音频（仅本机读取），光标跟随。

## 步骤
- [x] 速度图与音符时间表（纯函数，可测）：tick↔秒、按谱生成播放事件、总时长
- [x] 钢琴音色：程序合成（加法合成 + 非谐性 + 双弦拍频 + 击弦噪声），worker 预渲染各音高缓冲，无 worker 时主线程
- [x] 播放器：AudioContext 预读调度、暂停/定位/结束、钢琴与音频两路音量、音频偏移
- [x] 五线谱与简谱写入每小节的走带标记（小节矩形 + 起音位置），收集为页面比例坐标
- [x] 光标叠加层、自动跟随滚动、点击谱面定位、空格播放/暂停
- [x] 走带栏：播放/暂停、回到开头、时间与进度条、钢琴开关、打开音频、偏移；四语言
- [x] 打开的音频存 IndexedDB 独立存储（随工程移除），偏移存设置
- [x] 测试（单元 + 浏览器），README，构建
- [x] 合并进 main、推送部署、生产验证
- [x] 用户追问“PDF 上预览时叠加”：预览页即 PDF 版面，光标已叠加其上（说明，不写入下载文件）
